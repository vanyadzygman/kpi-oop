# CGW: Calculation and Graphical Work

Завдання 11. Створити програму – растровий графічний редактор

## Key Requirements

- Наявність виконуваного файлу, вихідних текстів та звіту;
- Програму зробити модульною та об’єктно-орієнтованою.

Деякі вимоги (функціональні та реалізації) повинні узгоджуватися з викладачем.

## Запуск

Модулі ES завантажуються лише через HTTP, тому `index.html` відкривається через локальний сервер
(VS Code Live Server, `npx serve` або `python -m http.server`). Браузер — Google Chrome або Microsoft Edge
(стандартні вікна відкриття/збереження файлів — File System Access API).

## Можливості

- Растр 24 біт RGB; меню «Файл»: Створити, Відкрити, Записати, Записати як, Вихід.
- Формати: читання BMP (1/4/8/16/24/32 біт), PNG, JPEG, GIF, WebP; запис BMP 24 біт (власний кодер), PNG, JPEG, WebP.
- Інструменти (Toolbar з підказками): виділення, олівець, пензель, розпилювач, гумка, заливка, піпетка, текст,
  точка, лінія, прямокутник, округлений прямокутник, еліпс, трикутник, ромб, шестикутник, стрілка, зірка.
- Колір контуру та заливки (ліва/права кнопка миші), товщина, режим «контур / заливка / контур і заливка».
- Undo/Redo, Cut/Copy/Paste (системний буфер обміну), масштаб, прокрутка, зміна розмірів полотна,
  масштабування, віддзеркалення, поворот, фільтри (сірий, негатив, сепія, яскравість, контраст, розмиття,
  різкість, контури, тиснення).
